# Redbelt-Club_Landing-Page
UFC Quixadá, Projeto Integrado II

Landing Page produzida para o cliente Redbelt Club, clube de artes marciais de Morada Nova-CE, da disciplina de Projeto Integrado II do curso Design Digital da UFC, Campus Quixadá.

A página possui responsividade tanto para web, quanto para dispositivos móveis, ajustando o tamanho e posição dos elementos conforme o tamanho da tela em que está sendo acessado o site.
